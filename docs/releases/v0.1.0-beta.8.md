# ShopAware v0.1.0-beta.8

Beta.8 builds on the qualified beta.7 release with safer camera-settings editing
and serialization of saved and active tuning. SQLite remains at schema 6.

## Changes

- Switching cameras cancels the prior load and ignores late results and errors.
  Another camera's settings cannot replace the currently selected camera's draft.
- Save operations prevent duplicate submissions, camera switching and edits until
  the response arrives. Failed saves retain the draft for retry.
- The editor shows unsaved changes, confirms discarding them when switching
  cameras, warns on browser unload, and offers Discard changes to restore the
  camera's last saved values. Loading failures have a Retry control.
- Numeric inputs use form validation, including plate-length ordering. Blank
  inputs remain blank instead of silently becoming zero.
- Concurrent mode-setting saves serialize database persistence and live detector
  updates under the camera lifecycle and tracking locks. Camera deletion and
  enable/disable operations cannot replace the runtime halfway through a save.
- A closed camera rejects settings changes before writing to the database.

## Qualification

Publication requires the exact pushed commit to pass backend tests, dashboard
lint/tests/build, both Server2 CPU Docker builds, health/authentication checks,
YOLO26 detection/pose CPU inference, H.264 evidence, schema verification, and
runtime checks after container recreation with the same encryption key.

Tests cover out-of-order camera responses, stale errors, retries, dirty-state
reversion, duplicate submissions, edits during save, request cancellation,
concurrent persistence/application, and closed-camera rejection.

Real-camera footage and sustained Server2 load acceptance remain operational
checks. Vehicle break-in and LPR outputs require human review; face capture does
not perform identity recognition or cross-camera matching.

See the [beta.8 upgrade guide](../SERVER2_BETA8_UPGRADE.md). Beta.7 remains a
qualified prior release; beta.5 and beta.6 must not be installed.
