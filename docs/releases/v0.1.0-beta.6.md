# ShopAware v0.1.0-beta.6

> SUPERSEDED — do not install this tag. It predates the final corrections. Use the beta.7 candidate only after its exact-commit release gate passes; see [beta.7 upgrade guide](../SERVER2_BETA7_UPGRADE.md). The original notes below are historical.

Beta.6 is the correctly pinned release candidate for the per-camera analytics tuning work. It contains the complete beta.5 branch fixes at a release tag that is created only after the exact commit passes the gated test, dashboard, CPU-container, model-inference, media and persistence qualification.

> Do not deploy the earlier `v0.1.0-beta.5` prerelease tag. It was created by an earlier workflow run before the final migration-preservation fixes and is superseded by beta.6.

## Added and preserved

- Dedicated administrator **Mode Settings** page.
- Independent persisted per-camera settings for Shoplifting, Vehicle break-in, LPR and Face Capture while preserving simultaneous multi-mode operation.
- Shoplifting: risk threshold, scoring window, candidate cooldown and loitering threshold.
- Vehicle break-in: heuristic threshold, near-vehicle dwell, required access interactions, interaction interval and candidate cooldown.
- LPR: same-plate cooldown, minimum OCR confidence and accepted plate length.
- Face Capture: capture cooldown, maximum images per continuous track and minimum crop quality.
- Additive SQLite schema 6 persistence in `cameras.mode_settings_json`.
- Existing beta.4 cameras snapshot their effective Shoplifting risk/loitering tuning, including prior customized global values, before becoming independently configurable.
- Settings apply without a service restart and are re-applied after process/container restart and RTSP stream-generation changes.
- Customer groups, user/camera ACLs, training, incidents, observations, retention, evidence recording, authentication, CSRF protection and encrypted RTSP credentials remain in place.

## Safety and interpretation boundaries

- Vehicle break-in output is a human-review candidate, never proof of a crime.
- LPR OCR remains an unverified candidate. Vehicle make/model remains unclassified.
- Face Capture remains anonymous continuous-camera-track grouping only. There is no identity recognition, embedding, watchlist, or cross-camera/cross-visit face matching.

The beta.6 tag is created only after the exact release commit passes:

- complete Python test suite;

Real hotel/store footage, nighttime LPR, real two-camera behavior, and sustained Server2 CPU/storage/event-latency qualification remain operational acceptance work rather than synthetic CI claims.
