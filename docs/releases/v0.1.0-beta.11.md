# ShopAware v0.1.0-beta.11

Beta.11 fixes anonymous face-history grouping across tracking restarts.
SQLite schema 6 and saved mode settings are unchanged.

## Fixed

- Numeric stream generations and person track IDs can restart from the same
  values. Each camera tracking context now has a random continuity marker that
  rotates whenever tracking resets, including reconnects, resolution changes,
  mode changes and runtime replacement. Newly persisted face observations include
  that marker in their subject key and metadata.
- The Analytics page groups captures by camera, continuity marker and track key.
  An uninterrupted track remains grouped, including across tuning-only changes.
- Historical captures without a valid continuity marker are shown individually.
  Their continuity cannot be reconstructed safely from the old numeric IDs.
  Existing observations and images are preserved without a database migration.

## Validation

Backend frame-processing regressions reproduced four subject-key collisions
before the fix, plus missing continuity metadata on reconnect. Six integration
cases now cover reload, enable/disable replacement, mode changes, resolution
changes, reconnect and tuning, including saved records returned by the API.
Five dashboard cases cover continuous grouping/order, session and camera
separation, conservative legacy handling and exclusion of plate observations.

The release gate requires the exact pushed commit to pass the complete backend
suite, dashboard lint/tests/build, both CPU container builds, health/authentication
checks, actual YOLO26 detection/pose CPU inference, H.264 evidence generation,
schema verification and runtime checks after container recreation with the same
encryption key.

Face Capture remains anonymous detection. This fix does not add identity
recognition, biometric matching or cross-camera/cross-visit linking. A track is
only the tracker's continuity estimate and requires human review.

Use the [beta.11 upgrade guide](../SERVER2_BETA11_UPGRADE.md) after the exact-commit
release gate passes. Real-camera accuracy and sustained Server2 load acceptance
remain operational checks. This release does not deploy Server2 or merge main.
