# ShopAware v0.1.0-beta.9

Beta.9 corrects analytics state lifetimes and removes a shared loitering-threshold
mutation during inference. Settings and SQLite schema 6 are unchanged.

## Fixed

- LPR now retains duplicate-suppression timestamps for the full configured
  cooldown, including intervals longer than the previous one-hour cleanup.
- Face Capture preserves the per-track image cap while a person remains on the
  same continuous camera track, even when no acceptable face crop has been saved
  for ten minutes. Brief detection gaps no longer immediately clear an old cap.
  Cleanup is based on the last observed track time and respects longer capture
  cooldowns; inactive state still expires.
- Shoplifting retains signals for the full configured scoring window, including
  windows longer than the previous two-minute inactive-track cleanup.
- Zone dwell signals and ROI dwell labels read the current camera's saved
  loitering threshold directly. Inference no longer changes the global default
  used when new cameras or migrated cameras receive their settings.

## Validation

Eleven added regression cases cover long LPR cooldowns and expiry, face-capture
caps and cooldowns across cleanup and temporary detection loss, scoring-window
boundaries, stable new-camera defaults during inference, and actual frame
processing with different camera dwell thresholds. Eight cases were first
observed failing against beta.8 before the fixes.

The release gate requires the exact pushed commit to pass the complete backend
suite, dashboard lint/tests/build, both CPU container builds, health/authentication
checks, actual YOLO26 detection/pose CPU inference, H.264 evidence generation,
schema verification and runtime checks after container recreation with the same
encryption key.

These counters remain in-memory stream/track state. Saved settings persist across
restarts; counters intentionally reset with replacement helpers or stream
generations. No identity recognition or cross-camera face matching is added.
Vehicle break-in and LPR results remain candidates requiring human review.

Use the [beta.9 upgrade guide](../SERVER2_BETA9_UPGRADE.md) after the exact-commit
release gate passes. Real-camera accuracy and sustained Server2 load acceptance
remain operational checks. This release does not deploy Server2 or merge main.
